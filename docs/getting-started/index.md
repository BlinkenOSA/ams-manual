# Getting started

AMS is organized around modules in the main menu. The modules visible to you depend on your assigned access groups; administrators can see all modules.

The two modules available to every signed-in user are the **Dashboard** and **Digitization Log**. Other modules support accessioning, archival description, finding aids, list management, locations, and research services.

![AMS Dashboard at desktop width](../assets/screenshots/getting-started/dashboard-desktop.jpg)

*The Dashboard in the desktop layout used throughout this manual.*

See [Dashboard](dashboard.md) for full-text search, collection statistics, logs, and analytics.

## Before you begin

You need:

- an active AMS account;
- membership in the access group for the work you perform; and
- the cataloguing or service information required by your institution.

If AMS shows an access-denied page, see [Roles and access](../reference/roles-and-access.md).

## Recommended learning path

1. [Sign in and learn the navigation](sign-in-and-navigation.md).
2. Review [common actions](common-actions.md) used throughout lists and forms.
3. Read the overview for the part of the archival workflow you perform.
4. Keep the [glossary](../reference/glossary.md) nearby for record relationships and abbreviations.
