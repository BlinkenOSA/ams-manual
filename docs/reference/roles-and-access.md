# Roles and access

AMS displays menu entries and protects routes according to account groups. Administrators can access every module.

| Access group | Main areas |
|---|---|
| All signed-in users | Dashboard, Profile, Digitization Log |
| Accessions | Accession Records, Donors |
| Archival Units | Archival Units |
| ISAAR | ISAAR-CPF |
| ISAD(G) | ISAD(G) |
| Finding Aids | Folders / Items, Missing Folders / Items |
| Unprocessed Materials | Unprocessed Materials |
| Authority Lists | Authority lists |
| Controlled Lists | Controlled lists |
| MLR | Master Location Register |
| Research | Researchers Database, request lists, digital requests |
| Restricted Decision Makers | Restricted Access Management |

## If access is denied

1. Confirm you opened the intended module.
2. Sign out and sign in again if your access was recently changed.
3. Capture the page address and the name of the module.
4. Ask an AMS administrator to verify your account and group membership.

Do not share credentials or use another person's account to work around an access problem.
