# Glossary

**Accession**
: A body of material transferred to the archives and documented as a transaction.

**Archival Unit**
: A structural unit in the archival hierarchy, represented in AMS as fonds, subfonds, or series.

**Authority list**
: A maintained set of named entities or terms, often with external identifiers and alternate forms.

**Container**
: A physical carrier or enclosure, such as a box, associated with a series and folder/item descriptions.

**Controlled list**
: A maintained set of permitted values used to make data entry and retrieval consistent.

**Finding aid**
: A description that helps identify and locate archival material, including container-, folder-, and item-level records.

**Fonds**
: The highest Archival Unit level currently represented by the AMS Archival Unit editor.

**ISAAR-CPF**
: International Standard Archival Authority Record for Corporate Bodies, Persons and Families.

**ISAD(G)**
: General International Standard Archival Description.

**MLR**
: Master Location Register, used to record physical storage locations and quantities.

**Original locale**
: The language or locale of original-language metadata paired with a translated or primary description.

**Reference code**
: The identifier used to locate and distinguish an Archival Unit or description.

**Series**
: An Archival Unit level below a fonds or subfonds.

**Subfonds**
: An Archival Unit level below a fonds and above a series.
