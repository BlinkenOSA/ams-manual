# Archival description

AMS separates the archival workflow into connected record types.

| Record type | Purpose |
|---|---|
| Donor | Identifies the person or organization transferring material |
| Accession | Documents the transfer and its initial content, rights, and location |
| Archival Unit | Establishes the fonds–subfonds–series hierarchy |
| ISAAR-CPF | Describes a creator or other authority entity |
| ISAD(G) | Describes an Archival Unit according to ISAD(G) areas |
| [Finding aid](../archival-finding-aids/index.md) | Describes containers, folders, and items within a series |

## Suggested sequence

1. Confirm or create the target archival fonds.
2. Confirm or create the donor.
3. Create the accession record and link it to the target fonds.
4. Add any required subfonds and series to the Archival Unit hierarchy.
5. Create or link ISAAR-CPF authority records.
6. Create the ISAD(G) description.
7. Add containers and folder/item descriptions in [Archival finding aids](../archival-finding-aids/index.md).

Existing data or legacy imports may require a different sequence. Follow local cataloguing policy when reconciling legacy identifiers.
