# Collections management

Collections-management modules support consistent description, physical control, and digitization.

- [Authority Lists](lists.md) provide reusable names and descriptive terms, including external authority connections.
- [Controlled Lists](controlled-lists.md) provide standardized values used by select fields throughout AMS.
- [Master Location Register](mlr.md) records storage positions and quantities.
- [Digitization Log](digitization.md) tracks digitization work and technical metadata.

Changes in these modules can affect many descriptive records. Search for an existing value before adding another and follow local approval procedures for vocabulary changes.
