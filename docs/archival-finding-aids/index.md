# Archival finding aids

Archival finding aids describe and manage material within an archival Series at container, folder, and item level. These modules connect the descriptive hierarchy established by Archival Units and ISAD(G) records with the physical containers and detailed records used by archivists and researchers.

| Module | Purpose |
|---|---|
| [Folders / Items](../archival-description/finding-aids.md) | Select a Fonds, Subfonds, and Series; manage containers; create and edit Folder / Item records; use templates and Table View; print labels; and control publication and status. |
| [Missing Folders / Items](../archival-description/finding-aids-missing.md) | Review Folder / Item records marked as missing and return them to non-missing status when appropriate. |
| [Unprocessed Materials](../archival-description/finding-aids-unprocessed.md) | Create, edit, and move containers assigned to the separate unprocessed-materials workflow. |

## How finding aids are structured

Finding Aids work within the archival hierarchy:

1. A **Series** belongs to a Fonds and, where applicable, a Subfonds.
2. A **Container** belongs to the selected Series.
3. **Folder / Item records** belong to a container and provide the detailed descriptions displayed in the Archival Catalog when published.

The [Archival Unit](../archival-description/archival-units.md) must therefore exist before its containers and Folder / Item records can be created. The corresponding [ISAD(G) record](../archival-description/isad-g.md) supplies the Series-level archival description and controls important publication relationships.

## Suggested workflow

1. Confirm that the required Fonds, Subfonds, and Series exist in Archival Unit.
2. Open **Folders / Items** and select the appropriate hierarchy.
3. Create or review the Series' containers.
4. Expand a container and create its Folder / Item records, either from a blank form or a Series-specific template.
5. Use **Table View** when repeated values need to be compared or corrected across the Series.
6. Review confidentiality, missing, access-rights, and publication status before making descriptions public.
7. Use **Label Print** to generate printable archival-box labels when the container metadata is ready.
8. Review records marked as missing in **Missing Folders / Items** and manage incoming unprocessed containers in **Unprocessed Materials**.

Digital-copy information shown in the container and Folder / Item tables is inserted automatically by the digital preservation workflows.

## Access

Access to **Folders / Items** and **Missing Folders / Items** requires the **Finding Aids** group. **Unprocessed Materials** uses its own permission group, so it may be available to a different set of users. See [Roles and access](../reference/roles-and-access.md) when a submenu or action is unavailable.
